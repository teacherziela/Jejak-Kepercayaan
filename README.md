# Jejak Kepercayaan – Pac-Maze Alam Melayu

Game standalone untuk Sejarah Tingkatan 2, Bab 4.1: Agama dan Kepercayaan Masyarakat Kerajaan Alam Melayu.

## Fail
- `index.html`
- `style.css`
- `game.js`

## Cara pasang di GitHub Pages
1. Cipta repository baharu di GitHub.
2. Upload ketiga-tiga fail di atas ke bahagian root repository.
3. Pergi ke Settings → Pages.
4. Pilih Deploy from a branch → `main` → `/root`.
5. Save dan tunggu GitHub Pages menghasilkan pautan.

Game tidak memerlukan server atau database.
